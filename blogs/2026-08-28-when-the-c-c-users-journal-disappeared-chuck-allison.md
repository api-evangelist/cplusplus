This article chronicles the rise and fall the C/C++ Users Journal, and the creation of The C++ Source , which filled the interim until isocpp.org came online. When The C/C++ Users Journal Disappeared by Chuck Allison From the article: Today, if you have a question, you search the web or have ask an AI chatbot. In the early 1980s there was the C Programming Language, but: there was no web there was no Stack Overflow, there was no GitHub, there was often no Internet access at all.
