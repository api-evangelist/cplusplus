PVS-Studio 8.00 has been released. This version features new analyzers for JavaScript, TypeScript and Go projects, new IDE plugins for WebStorm and GoLand, expanded support for MISRA C++ 2023, and much more. PVS-Studio 8.00 by Valerii Filatov From the article: In the release, we have also expanded the list of C and C++ compilers that are compatible with the PVS-Studio analyzer for these languages.
